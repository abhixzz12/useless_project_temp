### Project Description
Smart Distance Game is an Arduino-based interactive game where the player sets a target distance and tries to position their hand or an object as close to that distance as possible within a limited time. An HC-SR04 ultrasonic sensor measures the distance, while a Bluetooth module sends the game results to the user. The system calculates the score based on the difference between the target and actual distance and maintains a total score across multiple rounds.

### The Solution (that nobody asked for)
